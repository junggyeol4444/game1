# 도시 키우기 : 방치형 시티

빈 땅에서 시작해 도시를 키우는 모바일 방치형 게임.
도시 지도가 메인 화면이고, 모든 건물(사업 5종 + 시설 9종)을 눌러 들어간다.
저폴리 + 고정 아이소메트릭 아트.

기획안 v1(2026-08-18)의 코어 루프를 **플레이 가능한 상태로** 구현한 것이다.

---

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (--host 로 같은 와이파이의 폰에서도 접속 가능)
npm run build      # 타입체크 + 프로덕션 빌드 -> dist/
npm run preview    # 빌드 결과 확인
npm test           # 유닛 테스트 (세이브 · 문명 전환 · 경제 · 표기)
npm run check      # 타입체크 + 테스트
npm run sim        # 밸런스 시뮬레이터 (npm run sim -- --days 30)
npm run art:check  # 스프라이트 발주서 / 누락 현황

npm run android:open   # 빌드 + cap sync + Android Studio 열기
npm run android:sync   # 빌드 + cap sync 만
```

폰에서 테스트하려면 `npm run dev` 후 터미널에 찍히는 `http://<PC IP>:5173` 을 폰 브라우저로 연다.
홈 화면에 추가하면 PWA(전체화면)로 실행된다.

Capacitor 안드로이드 프로젝트는 붙어 있다. `android/`, `ios/` 는 전부 생성물이라
커밋하지 않는다 — 저장소를 처음 받았으면 `npx cap add android` 한 번.
자세한 건 [docs/NATIVE.md](docs/NATIVE.md).

## 왜 Unity가 아니라 웹인가

기획안 10장은 Unity를 잡았다. 이 구현은 TypeScript + Capacitor로 갔다. 이유:

- 이 게임의 코어는 숫자·UI 루프다. 3D 렌더링/물리가 없다.
- 1인 개발에서 가장 비싼 자원은 **반복 검증 속도**다. 웹은 링크 하나로 실기기 테스트가 되고, 빌드가 1초다.
- 광고/결제는 Capacitor 플러그인(AdMob, RevenueCat)으로 네이티브와 동일하게 붙는다.
- 밸런스 수식과 데이터는 `src/data/` 에 전부 분리해 두었으므로, 나중에 Unity로 옮기더라도 그대로 이식된다.

번들 크기는 gzip 19KB. 저사양 기기·신흥시장에서 유리하다.

## 화면 구조 (v1 추가분)

```
┌──────────────────────────┐
│ 👤시장 Lv.N  📦물자 💰돈 │  상단바
├──────────────────────────┤
│                          │
│        도 시             │  메인 뷰 — 드래그·핀치
│   3열 × 5행 격자 마을     │  건물 탭 → 진입
│   ⚠️ 병목이 건물 위에 뜸  │
│                          │
├──────────────────────────┤
│ [🔨 건설]   [🏙️ 레벨]    │
├──────────────────────────┤
│ 도감 메뉴 레벨 건설 미션 │  하단 메뉴바
└──────────────────────────┘
```

**도시의 모든 건물은 눌러서 들어간다. 예외 없음.**

| | 건물 | 하는 일 |
|---|---|---|
| 사업 5 | ⛏️광산 🏭공장 🎣어항 🎡놀이공원 🏢기업 | 돈을 번다 |
| 시설 9 | 🏠주거지 🏪상가 🏥병원 🏫학교 🚒소방서 👮경찰서 🌳공원 ⚡발전소 🛣️도로 | 도시 능력치를 올린다 |

업그레이드하면 **도시 화면에 즉시 반영된다.** 반영은 3단계:
1. **즉시** — 층이 늘고 배가 늘고 굴뚝 연기가 진해진다
2. **마일스톤** — 총 레벨 10/25/50/100에서 건물 외형 자체가 교체된다
   (갱도→채굴장→광산단지 / 단독주택→아파트→고층단지 / 화력→댐→원자력→신재생)
3. **도시 레벨** — 배경과 지형이 바뀐다 (들판→마을→소도시→도시→대도시)

도시가 살아 있게 하는 것: 인구에 따라 거리를 걷는 사람 수, 도로 레벨에 따라 차량 통행량,
기기 시간에 따른 주간/야간 조명, 화재 시 소방차 출동, 상시 순찰차.

## 아트 — 에셋 파일에서 온다

**그림을 코드로 그리지 않는다.** 건물·캐릭터·차량·타일은 전부 `public/art/` 의 이미지 파일에서
온다. 파일이 없으면 회색 플레이스홀더가 뜬다 — 임시 그림을 진짜 아트로 착각하지 않게 하려는 것이다.

```bash
npm run art:check   # 필요한 스프라이트 78개와 누락 현황
```

**현재 0 / 78.** 아트 팩을 넣어야 한다. 어떤 팩을 어떤 규격으로 넣는지는 [docs/ART.md](docs/ART.md).

기획서 아트 문서의 방향(고정 아이소메트릭 · 저폴리 · 밝은 톤 · 지정 팔레트)은
투영·카메라·UI·팔레트 쪽에 반영되어 있다:

- 2:1 아이소메트릭 직교 투영, 회전 없음, 확대/이동만 (`src/ui/scene/iso.ts`)
- 지정 팔레트 (`src/data/palette.ts`) — 하늘 `#9FD8E8` · 지면 `#A8C97F` · 도로 `#B8B8B0` ·
  물 `#6FC3DF` · 강조 `#FFC845` · 그림자는 검정이 아니라 푸른빛 `#7A9BC4`
- UI: 둥근 모서리 12~16, 그림자 대신 어두운 테두리, 단색 버튼 + 흰 글자
- 건물 외형은 총 레벨에 따라 단계가 바뀐다 (스프라이트 키가 `_1` → `_6` 으로 교체된다)

## 사업 내부 — 12층 구조

기획서 '광산 상세'대로, 모든 사업이 **유닛 12개 + 공통 배율 장치 1개** 구조다.

```
지상부   사업 요약 · 엘리베이터(전 층 배율) · [▶미니게임] [⚡2배]
──────────────────────────────
1층  작업자 · 암벽 · 적재함 · 진행바     [Lv +N] [설비/매니저]
2층  ...
12층 🔒 해금 3.72T
──────────────────────────────
[x1] [x10] [x100] [최대]
```

- 층마다 지층이 다르다 — 흙층(석탄) → 암반(철) → 적색(구리) → 청색(은) → 흑색(금) → 결정층(보석)
- 레벨업 시 화면 속 작업자가 1→5명으로 늘고, 마일스톤마다 장비가 바뀐다
  (곡괭이 → 착암기 → 소형 드릴 → 대형 드릴 → 굴착기 → 자동 굴착기 → 레이저 → 로봇 → 플랜트)
- **엘리베이터**는 전 층에 곱해지는 배율 8단계(x1 → x17). 3단계부터 **보석**이 재료로 들어간다.
  보석은 미니게임 정타로만 나온다 — 자동화로는 못 얻는다

## 게임 규칙 (구현된 것)

### 진행 축 4개
| 축 | 주기 | 내용 |
|---|---|---|
| 사업 성장 | 분 | 유닛 12개 레벨업 · 설비 · 매니저 · 엘리베이터 |
| 시설 성장 | 시간 | 시설 9종 레벨업. 도시 전체 능력치 |
| 도시 레벨 | 일 | 누적 세수로 상승. 신규 건물 해금 + 지형 변화 |
| 문명 전환 | 주~달 | 도시를 전부 허물고 **다음 문명**으로 → 유산 → 영구 강화 7종 |

### 자동화 4단계 (기획서 7장)
| 단계 | 방법 | 효율 | 남는 것 |
|---|---|---|---|
| 1 수동 | 탭 / 미니게임 | 100% (직접 돌릴 때만) | — |
| 2 반자동 | 설비 배치 | 50% 자동 | 미니게임 |
| 3 자동 | 매니저 배치 | 100% 자동 | 미니게임 |
| 4 고효율 | 유산 '초과 가동' | 100%+ | 미니게임 |

판정할 때마다 소리 · 튀는 글자 · 화면 흔들림이 붙는다. 정타를 연속하면
콤보음이 **반음씩 올라간다** — 숫자를 안 봐도 연속이 이어지는 게 귀로 들린다.
판이 끝나면 성적표(등급 S~F · 성공률 · 배율 · 보상 · 특산물 · '한 판 더')가 뜬다.

자동화해도 미니게임이 남는 이유는 **자동화로 못 얻는 것**이 거기 있기 때문이다 —
보석(광산) · 고급 규격품(공장) · 희귀 어종(어항) · 만족도(놀이공원) · 투자 자금(기업).

### 미니게임 5종 (하루 3판 무료 + 광고 최대 5판)
| 사업 | 게임 | 조작 | 환산초 |
|---|---|---|---|
| 광산 | 광맥 캐기 | 타이밍 탭 | 3,600 |
| 공장 | 분류 라인 | 좌/우 탭 | 5,400 |
| 어항 | 릴링 | 홀드 | 7,200 |
| 놀이공원 | 손님 안내 | 드래그 | 10,800 |
| 기업 | 거래 | 저점 매수 · 고점 매도 | 14,400 |

광맥 캐기는 기획서 규격 그대로다 — 정타 ±8% ×1.0 / 근접 ±20% ×0.5 / 빗나감 ×0.1,
커서 왕복 1.6초→0.8초, 광석 출현 1.2초 간격, 콤보 3·5·8·12·15연속에 ×1.2~×3.0,
보석 광맥 5% 확률(판정 ±5%).

보상 = `초당산출 × 환산초 × 성적배율`, 성적배율 = `0.5 + 성공률 × 2.5`.
성공률 80% 이상이면 해당 사업 ×2, 95% 이상이면 ×3 을 30분간 받는다.

### 도시 자원 / 병목 (기획서 8장)
```
광산 ─원석→ 공장 ─제품→ 기업 ─매출→ 도시(세수)
어항 ─식재료→ 놀이공원 ─관광객→ 인구
시설 ─배율→ 전 사업        물자 ─소비→ 건설·확장
```
| 상태 | 원인 | 지도 표시 |
|---|---|---|
| 가동률 하락 | 상위 자원 부족 | ⚠️ 해당 사업 위 |
| 전 사업 감속 | 전력 부족 | ⚡ 발전소 위 |
| 전 사업 감속 | 노동력 부족 | 🧑 주거지 위 |
| 산출 절반 | 화재 (소방서가 예방) | 🔥 + 소방차 출동 |
| 자금 손실 | 도난 (경찰서가 차단) | 🚨 |

전력·노동력 수요는 **유닛 레벨의 로그**(Lv.1→1, Lv.100→7)로 잡아 숫자가 읽히는 범위에 머문다.
부족해도 최소 25%는 돌아간다.

### 자원 사슬
```
광산 ─원석→ 공장 ─제품→ 기업 ─매출→ 도시(세수)
어항 ─식재료→ 놀이공원 ─관광객→ 인구 ─노동력 배율→ 전 사업
```
- **도시 레벨 12 전까지는 사슬이 꺼져 있다.** 초반 3탭은 완전히 독립 작동한다.
- 상위 자원이 모자라면 가동률이 떨어지지만 **최소 25%는 항상 돌아간다**(유산 강화로 최대 75%까지 상향).
  스트레스가 아니라 "저기를 키워야 하는구나"라는 신호로 쓰기 위한 장치.
- 각 사업은 자원과 현금을 **동시에** 번다. 하위 탭이 자원을 소비해도 상위 탭의 수입은 줄지 않는다.

- 저금통은 도시 레벨 8부터 등장하고, 가득 차기 전까지 가격을 숨긴다
- **확률형 아이템(가챠) 없음** — 국내 확률 표시 의무 규제를 피하기 위한 의도적 설계

### 수치표에서 바꾼 것 하나

도시 레벨 요구 세수의 배수를 **×8 → ×78** 로 올렸다.
×8 그대로 두면 수입 곡선이 훨씬 빨라서 **16레벨 전부가 1시간에 소모된다**(측정).
수치표가 "전부 시작값, 프로토타입 측정 후 조정" 전제이므로, 같은 문서 9장의 밸런싱 목표치에
맞도록 조정했다. Lv.1~3의 요구치(0 / 5,000 / 50,000)는 문서 그대로 두었다.
상수는 `src/data/buildings.ts` 의 `CITY_REQ_GROWTH` 한 줄이다.

나머지 수치 — 층별 해금비용·rate·산출·사이클, 매니저 = 해금비용×5, 엘리베이터 8단계,
사업별 기준 배수, 시설 base/rate/상한, 미니게임 판정과 환산초, 오프라인 5단계,
사업별 기준 배수, 시설 base/rate/상한 — 은 전부 문서 값 그대로다.
재개발 공식만 문명 전환 기준으로 갈아탔다 (`docs/DESIGN.md` 6장).

## 문명 전환 — 석기 시대에서 시작한다

이 게임은 **도시가 아니라 빈 들판에서 시작한다.** 첫 건물은 움집과 돌 채취장이다.
목표 도시 레벨에 닿으면 **전부 허물고 다음 문명으로 넘어간다.**

```
석기 → 청동기 → 철기 → 중세 → 르네상스 → 산업혁명 → 근대 → 정보화 → 우주
Lv.7   Lv.9    Lv.11  Lv.13   Lv.15     Lv.17     Lv.19   Lv.21    Lv.23   ← 졸업 목표
 x1     x3      x9     x27     x81       x243      x729    x2,187   x6,561 ← 비용 배율
x1.00  x1.08   x1.17  x1.26   x1.36     x1.47     x1.59   x1.71    x1.85   ← 사이클 배율
```

**전환은 완전 초기화다. 산출 보너스가 없다.**
넘어갈수록 건설·업그레이드가 비싸지고 사이클이 느려진다. 진행을 되돌려 주는 건 유산 강화뿐이다.

- 문명이 바뀌면 **사업 5종 · 시설 9종 · 도시 규모 5단계 이름과 아이콘, 지도 팔레트가 전부 바뀐다.**
  석기 시대의 광산은 `돌 채취장`, 발전소는 `큰 모닥불`, 도시 최고 단계는 `큰 부족`이다.
- 리셋: 자금 · 물자 · 도시 레벨 · 사업 · 시설
- 유지: 유산 🏺 강화 · 보석 · 도감 · 상점
- `기업`은 도시 Lv.15에 열리므로 산업혁명 이전 문명에는 아예 없다. 초기 문명이 작은 건 의도다.
- 우주 시대에서 또 전환하면 시대는 유지하고 목표 레벨만 +2 되며 다시 세운다 (루프가 끝나지 않는다).

전환 시점 측정 (탐욕 AI · 하루 4세션 × 6분):
`18시간 → 3일 → 10일 → 34일 → 254일`. 실제 유저는 이보다 훨씬 느리다.
클리어하는 게임이 아니라 계속 굴리는 게임이다.

정의는 `src/data/eras.ts`, 진행 로직은 `src/core/era.ts`, 측정은 `docs/DESIGN.md` 6장.

## 첫 60초 튜토리얼

`src/ui/tutorial.ts`. 읽는 튜토리얼이 아니라 **누르는 튜토리얼**이다.
7단계 전부 실제 조작 1개씩이고, 조건이 충족되면 자동으로 넘어간다. '다음' 버튼이 없다.

```
돌 채취장 누르기 → 작업터 탭 3회 → 레벨업 → 설비 → 사람 배치 → 도시로 → 움집 건설
```

자동화 4단계 중 3단계까지를 첫 세션에 직접 겪게 한다.
이 게임이 "숫자 올리기"가 아니라 "자동화 세팅"이라는 걸 60초 안에 보여주는 게 목적이다.

화면을 막지 않는다 — 눌러야 할 곳만 링으로 뚫고 나머지를 어둡게 한다.
단계는 `state.tutorial` 에 저장되고, 언제든 건너뛸 수 있다.

12종: 곡괭이질 · 사이클 · 레벨업 · 설비 · 사람 배치 · 완공 · 해금 · 마일스톤 ·
코인 · 보상 · 문명 전환 · 자금 부족.

매니저를 다 붙이면 사이클이 초당 수백 번 끝난다 → 큐마다 **초당 재생 횟수 상한**을 둔다.
AudioContext 는 브라우저 정책 때문에 첫 입력에서 한 번만 만든다.

순간 연출은 `src/ui/scene/burst.ts` — 건물 단계가 바뀌면 0.8초 먼지가 교체를 가리고,
유닛이 마일스톤을 넘으면 링이 퍼진다. 문명 전환은 전 건물이 동시에 무너져서 도시 전체가 먼지다.
`설정 > 소리`, `설정 > 애니메이션 > 줄이기` 로 각각 끌 수 있다.

## 도감 — 문명이 곧 수집 메타다

도감 키가 `시대id:건물id` 다. 전체가 **9개 문명 × 건물 14종 × 외형 단계**라,
문명 하나를 통째로 지나가야 그 시대 칸이 채워진다. 지나간 문명 기록은 영구히 남는다 —
전환이 잃기만 하는 게 아니라는 근거다.

안 가본 시대는 잠금이고 `도시 Lv.N 에서 넘어옵니다` 로 조건을 보여준다.
다음 문명이 뭔지 미리 보이는 게 전환 동기다.

이름표가 붙는 수집품 2종: 희귀 어종 9(낚시), 놀이기구 9(놀이공원).
성적이 좋을수록 귀한 게 나온다. 나머지 특산물은 개수만 쌓인다.
