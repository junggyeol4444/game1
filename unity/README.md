# 도시 키우기 — Unity 모바일 프로젝트

기획안의 원래 요구대로 만든 Unity 프로젝트다. `unity/` 폴더를 Unity Hub에서 열면 된다.

## 현재 포함

- Unity 2022.3 LTS 프로젝트 구조
- 세로 모바일 Canvas와 런타임 부트스트랩
- 5개 사업 × 12개 유닛 데이터 구조
- 5개 사업 탭과 각 사업의 12개 유닛 조작 UI
- 도시 레벨·이전 유닛 기준 해금, 수동 작업 사이클, 매니저 자동 생산
- 레벨업, 마일스톤, 사이클 단축, Lv.12 이후 자원 사슬과 최소 25% 가동
- 시설 9종 건설·강화, 인구/전력 가동률, 상가 세수와 학교 산출 배율
- 석기부터 우주까지 9개 문명 전환과 유산 획득·도시 초기화
- 로컬 `PlayerPrefs` JSON 저장, 직전 백업, 10초 자동 저장
- 기기 UTC 기준 최대 2시간 오프라인 수익
- 보상형 광고·일회성 결제를 연결할 `IMonetizationService` 경계
- 에디터 밖에서 SDK 미설정 시 보상·결제가 반드시 실패하는 안전 기본값
- 매 프레임 움직이는 시민 24명과 주야간 배경 변화

빈 Scene 하나를 열고 Play해도 `RuntimeBootstrap`이 게임·카메라·도시·UI를 자동 생성한다.
이후 Unity Editor에서 프리팹과 실제 GPT 스프라이트로 교체할 수 있도록 런타임 로직을 분리했다.

## 아직 이식할 것

- 미니게임 5종, 미션·출석·도감 UI
- Unity IAP / Mobile Ads 실제 프로젝트 설정
- 최종 스프라이트와 애니메이터 컨트롤러
- Android/iOS 실기기 검증과 밸런스

기존 TypeScript 구현은 수치·행동 대조용 레퍼런스로 루트에 유지한다. Unity 이식 완료 후 제거한다.
