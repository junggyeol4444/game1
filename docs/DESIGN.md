## 2. 기획서에서 바꾼 것

### 2-0. (수정) 1차 구현이 기획안 2장을 정면으로 어겼다 — 목록 UI → 장면
첫 구현은 사업 탭이 "아이콘 + 이름 + 숫자 + 버튼" 목록이었다. 이건 기획안 2장이
**"순수 방치형은 숫자만 올려서 유저층이 좁다"**고 지목한 바로 그 형태이고,
9장의 광고 소재("빈 땅 → 도시 타임랩스")도 뽑을 수 없다. 참고작으로 적은
Idle Miner Tycoon은 갱도가 보이고 광부가 움직이는 게임이다.

→ UI 레이어를 전부 다시 만들었다. 게임 로직(economy/progression/밸런스)은 그대로다.
- 유닛 1개 = **움직이는 장면 밴드 1개** (`src/ui/scene/bands.ts`)
- 사업 탭 상단 = **사업장 전경** (`site.ts`)
- 도시 홈 = **자라는 도시 전경** (`city.ts`) — 홈 화면의 주인공
- 진행바 대신 장면 자체가 진행을 보여준다. 레벨이 오르면 화면 속 인력이 1→6명으로 늘어난다.
- 에셋 0개. 전부 캔버스에 코드로 그린다(1인 개발 · 용량 · 광고 소재 재활용).

### 2-1. 엔진: Unity → TypeScript + Capacitor
근거는 README 참고. 밸런스 데이터가 `src/data/` 에 순수 데이터로 분리되어 있어 Unity 이식 시 그대로 옮겨진다.

### 2-2. 탭 해금 시점을 뒤로 미룸
기획서에는 해금 순서만 있고 시점이 없었다. 시뮬레이터로 측정한 결과 초기 설계(도시 Lv.1/3/6/10/14)로는 **한 시간 안에 5탭이 전부 열려** 중기 루프가 사라졌다.
→ Lv.1 / 3 / 7 / 12 / 17 로 조정. 재개발은 Lv.20.

### 2-3. 자원 사슬을 "느슨한 병목"이 아니라 "가동률 하한"으로 구현
기획서 주의사항("사슬이 빡빡하면 스트레스")을 수치로 못박았다:
- 상위 자원이 0이어도 **최소 25% 가동** (설계도 강화로 최대 75%)
- 각 사업은 자원과 현금을 **동시에** 번다. 하위 탭이 자원을 먹어도 상위 탭 수입은 안 줄어든다
- 사슬은 도시 Lv.12부터 켜진다 (그 전까지 3탭 완전 독립)

즉 사슬은 "막는 장치"가 아니라 **"어느 탭을 키워야 하는지 알려주는 신호"**로 설계했다. 사업 탭 상단에 `가동률 62%` 로 항상 노출된다.

### 2-4. 저금통을 금액이 아니라 포인트로 채움
수입이 지수적으로 커지는 게임에서 "누적 금액"으로 채우면 진행률 표시가 무의미해진다.
→ 업그레이드 구매 +1 / 광고 +5 / 미션 +3 / 도시 레벨업 +20, 목표 300포인트.
보상은 개봉 시점의 초당 수입 8시간치로 환산. 도시 Lv.8 전에는 아예 노출되지 않는다.

## 4. 밸런스 구조 (재현 가능하게 남김)

`npm run sim -- --days 21` 로 언제든 재측정 가능하다.

핵심 수식:
- 유닛 가격: `baseCost × costScale × costGrowth^level` (growth 1.07~1.15)
- 유닛 산출: `baseOutput × outScale × level × 마일스톤 × 사업배율`
- 회수 기간: `payback = 3.2 × costScale / outScale` 초
- 도시 레벨 요구 누적 세수: `60 × (4.2^(L-1) − 1) / 3.2`
- 재개발 설계도: `80 × √(이번 회차 누적수익 / 1e14)`

사업별 회수 기간 (뒤로 갈수록 길다 = 새 탭이 기존 탭을 즉시 무의미하게 만들지 않는다):

| 사업 | 해금 | payback |
|---|---|---|
| 광산 | Lv.1 | 3.2초 |
| 공장 | Lv.3 | 19초 |
| 어항 | Lv.7 | 115초 |
| 놀이공원 | Lv.12 | 691초 |
| 기업 | Lv.17 | 4160초 |

> 이 비율을 건드릴 때는 반드시 시뮬레이터를 다시 돌릴 것. 초기 설계는 payback이 전부 같아서
> 새 탭 해금 순간 수입이 250배 뛰었고, 도시 레벨 20개가 40분 만에 소모됐다.

### 추가분에서 판단해서 바꾼 것

- **전력/노동력 수요를 산출량이 아니라 유닛 레벨의 로그로** 잡았다.
  산출량 기준으로 하면 수요가 1e8 단위가 되어 "전력 452 / 606" 같은 읽히는 숫자가 안 나온다.
- **"전력 부족 시 사업 정지"를 최소 가동률 25%로 완화**했다. 완전 정지는 복귀 유저를 잃는다.
  대신 도시 화면에 ⚡ 마커를 크게 띄운다.
- **학교/상가 배율을 처음 설계의 절반으로 낮췄다.** 시뮬레이터에서 산출 x34가 나와
  시설이 다른 축을 전부 압도했다. 지금은 x9.5 수준 (14일 기준).
- **도시 지도를 가로 띠가 아니라 3열×5행 격자**로 배치했다. 가로 띠는 세로 화면에서
  건물이 한 번에 하나밖에 안 보였다.

| 수치 5장 도시 레벨 | `buildings.ts CITY_LEVELS` | 해금 순서 그대로 / **배수만 ×8→×78 조정** |
| 수치 6장 미니게임 보상 | `config.ts minigame` | 환산초·성적배율·일시배율 그대로 |
| 수치 7장 오프라인 | `economy.ts` `config.ts` | 효율/상한 5단계, 물자 소비 |

| 세이브 1장 저장 트리거 | `game.ts` | 구매·해금·매니저·미니게임·광고·결제·백그라운드·60초 |
| 세이브 2장 데이터 구조 | `save.ts serialize/deserialize` | 문서 스키마로 직렬화. 큰 수는 문자열 |
| 세이브 5장 마이그레이션 | `state.ts migrate` | 신규 필드 기본값 채움 |
| 세이브 6장 무결성 | `save.ts` | 체크섬 + 백업 1개 + 복구. **암호화는 난독화까지만** |

### 문서에서 바꾼 것

1. **도시 레벨 요구 세수 배수 ×8 → ×78.** ×8이면 16레벨이 1시간에 소모된다(시뮬레이터 측정).
   수치표가 "측정 후 조정" 전제이고, 같은 문서 9장의 밸런싱 목표치에 맞췄다.
   Lv.1~3 요구치는 문서 그대로.
2. **기본 인구 50 · 기본 전력 60.** 둘 다 0에서 시작하면 1층조차 못 돌려 데드락이 난다.
   주거지/발전소가 없는 마을의 기본값으로 뒀다.
3. **전력 부족 시 완전 정지 대신 최소 15% 가동.** 복귀 유저를 잃지 않기 위해서다.
   인구 부족은 문서대로 "가동 유닛 수 = 인구/요구량" (앞 층부터 순서대로 멈춤).
4. **세이브 암호화는 난독화 + 체크섬까지.** 웹에서 기기 키 암호화는 의미가 없어서
   네이티브 빌드에서 교체하도록 남겼다.

## 6. 문명 전환 (2026-08-20 방향 변경)

요청: **"도시부터 시작 말고 완전 처음부터 시작하는 걸로 하자 / 특정 돈 발전되면 다 허물고 다른 문명으로 넘어가는 거 넣어 놓자"**
후속: **"문명이 넘어가면 발전이 느려지고 업글하는 게 더 비싸져야지. 누가 방치형을 3달 만에 클리어해."**

기획서의 **재개발(프레스티지)을 문명 전환으로 대체**했다. 리셋할 때마다 문명 자체가 바뀐다 —
이름·아이콘·팔레트·도시 규모 호칭이 전부 갈린다.

### 전환은 완전 초기화다 — 산출 보너스가 없다

1차 구현은 시대마다 영구 산출 배율(x4)을 줬다. **틀렸다.**
"다 허물고 다시 시작"이라고 해놓고 수입 보너스를 주면 초기화가 아니고, 그것 때문에
9개 문명이 시뮬레이터에서 3달에 소모됐다.

지금은 반대다:

| 시대 | 졸업 도시 Lv. | 비용 배율 | 사이클 배율 |
|---|---|---|---|
| 석기 | 7 | x1 | x1.00 |
| 청동기 | 9 | x3 | x1.08 |
| 철기 | 11 | x9 | x1.17 |
| 중세 | 13 | x27 | x1.26 |
| 르네상스 | 15 | x81 | x1.36 |
| 산업혁명 | 17 | x243 | x1.47 |
| 근대 | 19 | x729 | x1.59 |
| 정보화 | 21 | x2,187 | x1.71 |
| 우주 | 23 (+2/회) | x6,561 | x1.85 |

- **비용 배율** — 유닛 해금·레벨업·설비·매니저·엘리베이터·시설, 전부 곱한다
  (`economy.ts unitCost/unitUnlockCost/managerCost/equipCost/hoistCost`, `facilities.ts facilityCost`).
- **사이클 배율** — 한 사이클이 느려진다 (`economy.ts cycleTime`).
- 진행을 되돌려 주는 건 **유산 강화뿐이다.** 시대 자체는 보너스를 주지 않는다.

### 전환 조건을 "세수 절대값"이 아니라 "도시 레벨"로 잡은 이유

시대마다 목표 세수를 x25씩 올려 봤더니 9개 문명이 **2일 8시간**에 다 소모됐다.
회차 안에서 수입이 지수로 폭발하므로 x25 정도는 몇 시간이면 따라잡힌다.
도시 레벨 요구량은 레벨당 x78이라 그런 식으로 흡수되지 않는다.
그래서 목표를 **도시 레벨**로 적었다 (`EraDef.advanceLevel`, 7부터 2씩).

### 측정 (`npm run sim -- --days 400`, 탐욕 AI · 하루 4세션 x 6분)

```
석기 → 청동기      18시간
청동기 → 철기      3일 8시간
철기 → 중세        10일 12시간
중세 → 르네상스     34일 8시간
르네상스 → 산업혁명  254일 12시간
근대 이후          400일 시뮬레이션 안에 도달 못 함
```

한 회차가 갈수록 길어진다 (18시간 → 3일 → 10일 → 34일 → 254일).
탐욕 AI가 이 정도이므로 실제 유저 기준으로 **후반 시대는 사실상 엔드 콘텐츠**다.
클리어하는 게임이 아니라 계속 굴리는 게임이 목표라 이 곡선을 택했다.

### 유산 (설계도 대체)

- 이름/아이콘: **유산 🏺** (내부 자원 id 는 세이브 호환 때문에 `blueprint` 유지)
- 획득: `baseGain(12) x 2^(시대 단계) x sqrt(목표 초과 배수)`
  — 시대마다 x2. 강화 비용이 구매마다 x1.5라 이래야 강화 레벨이 계속 오른다.
- 목표를 넘겨서 더 키우고 넘어가면 sqrt만큼 더 받는다. 이득이지만 완만해서 무한정 미루는 게 답이 되지 않는다.
- 사용처는 기존 설계도 강화 7종 그대로 (`src/data/legacy.ts`).

### 시작점이 도시가 아니다

- `createInitialState()` 는 **석기 시대 빈 들판**에서 시작한다. 첫 건물은 움집과 돌 채취장이다.
- `기업`은 도시 Lv.15에 열리므로 **산업혁명(졸업 목표 Lv.17) 이전 문명에서는 존재하지 않는다.**
  자원 사슬(도시 Lv.12부터)도 중세 이후에나 작동한다. 초기 문명이 작은 건 의도다.

### 아트

- **`buildings/<시대id>/<건물>_<단계>` 를 먼저 찾고, 없으면 `buildings/<건물>_<단계>` 로 떨어진다**
  (`art/keys.ts buildingKeysFor`). 시대 전용 스프라이트가 없어도 게임은 돈다.
- `npm run art:check` 가 필수(시대 공통 78키)와 선택(시대 전용 9x78키)을 나눠서 보여준다.
- 지면·하늘·물·도로 색은 `EraDef.palette` 에서 온다. 문명이 바뀌면 지도 색조가 통째로 바뀐다.

### 마지막 시대 이후

우주 시대에서 또 전환하면 시대는 그대로 두고 **목표 도시 레벨만 +2** 되며 도시를 다시 세운다.
비용 배율은 우주 시대 값(x6,561)을 유지한다. 루프가 끝나지 않게 하기 위한 것이다.

## 7. 첫 60초 튜토리얼

`src/ui/tutorial.ts`. 광산 문서 7장.

**읽는 튜토리얼이 아니라 누르는 튜토리얼이다.** 매 단계가 실제 조작 1개고,
조건이 충족되면 자동으로 넘어간다. '다음' 버튼이 없다.

| # | 지시 | 왜 | 완료 조건 |
|---|---|---|---|
| 0 | 돌 채취장을 누르세요 | 도시의 모든 건물은 들어갈 수 있습니다 | 광산 화면 진입 |
| 1 | 작업터를 눌러 한 번 캐 보세요 | 누를 때마다 한 사이클이 돕니다 | 탭 3회 |
| 2 | 레벨을 올리세요 | 한 번에 캐는 양이 늘어납니다 | 1번 유닛 Lv.3 |
| 3 | 설비를 놓으세요 | 안 눌러도 절반 속도로 돕니다 | `equip` |
| 4 | 사람을 붙이세요 | 이제 완전 자동입니다 | `manager` |
| 5 | 도시로 돌아가세요 | — | 도시 화면 |
| 6 | 건설을 눌러 움집을 지으세요 | 사람이 살아야 작업터가 돌아갑니다 | 주거지 Lv.1 |

즉 **자동화 4단계 중 3단계까지를 첫 세션에 직접 겪게 한다.**
이 게임이 "숫자 올리기"가 아니라 "자동화 세팅"이라는 걸 60초 안에 보여주는 게 목적이다.

### 구현

- 화면을 막지 않는다. `.tut-ring` 이 대상만 링으로 감싸고 `box-shadow: 0 0 0 9999px` 로
  나머지를 어둡게 한다. 링은 `pointer-events: none` 이라 그대로 누를 수 있다.
- 지시 카드는 대상이 화면 아래쪽이면 위로 올라간다 (`.tut-card.top`).
- 도시 지도의 건물은 캔버스라 DOM 타깃이 없다. `MapView.rectOf(id)` 로 화면 좌표를 받아 링을 건다.
- 단계는 `state.tutorial` (0~6, `-1` = 종료). 세이브 `player.tutorial_step` 에 저장된다.
  **필드가 없는 세이브는 종료로 친다** — 튜토리얼 도입 전 유저에게 다시 띄우지 않기 위해서다.
- 언제든 '건너뛰기'. 다시 안 뜬다.

### 검증

`tools/smoke.mjs` 가 지시대로만 눌러서 끝까지 간다.
매 단계 스크린샷(`01c-tut-*.png`)을 남기고 `0 -> 1 -> ... -> 6 | 최종 -1` 을 출력한다.

## 8. 사운드 · 타격감

`src/core/audio.ts` (효과음) + `src/ui/fx.ts` (화면 흔들림). 아트 문서 10장, 9장.

### 음원 파일을 쓰지 않는다

**WebAudio 로 전부 합성한다.** 오실레이터 + 노이즈 버퍼 조합이다.

- 에셋 0개 · 용량 0 · 로딩 0. 1인 개발이라 음원 발주 대신 코드로 만들었다.
- 톤이 마음에 안 들면 `CUES` 의 숫자(주파수·길이·파형)만 고치면 된다.
- 나중에 실제 음원으로 갈아끼울 때는 `Cue.play` 안쪽만 파일 재생으로 바꾸면 호출부는 그대로다.

### 큐 12종

| 큐 | 언제 | 소리 |
|---|---|---|
| `tap` | 수동 가동 | 노이즈 한 방 + 낮은 몸통 (곡괭이가 돌에 맞는 소리) |
| `cycle` | 사이클 완료 · 적재 | 아주 짧은 상승 블립 |
| `buy` | 레벨업 | 2음 상승 |
| `equip` | 설비 배치 | 노이즈 + 톱니 상승 (기계 걸리는 소리) |
| `manager` | 사람 배치 | 3음 아르페지오 |
| `build` | 건물 완공 | 저역 쿵 + 먼지 노이즈 + 종 |
| `unlock` | 신규 해금 | 4음 상승 |
| `milestone` | 마일스톤 · 엘리베이터 | 밝은 3화음 |
| `coin` | 현금 획득 | 짧은 2음 |
| `reward` | 보상 수령 | 4음 상승 |
| `era` | 문명 전환 | 무너지는 저역 하강 0.9초 → 새 문명 화음 |
| `deny` | 자금 부족 | 하강 2음 |

### 자동화 폭주 대응

매니저를 다 붙이면 사이클 완료가 **초당 수백 번** 난다. 그대로 재생하면 소음이고,
오실레이터 수백 개가 매 초 생성되어 성능도 무너진다.

큐마다 **초당 최대 재생 횟수**를 둔다 (`Cue.limit`). `cycle` 은 8회/초, `tap` 은 14회/초.
넘으면 그냥 버린다. 사이클 완료 감지도 사업 화면이 열려 있을 때만 하고(10Hz 샘플링),
지도 화면에서는 아예 소리를 내지 않는다.

### 브라우저 자동재생 정책

AudioContext 를 페이지 로드 시 만들면 `suspended` 로 잡힌다.
**첫 `pointerdown` 에서 한 번만** 만든다 (`unlockAudio()`, `app.ts`).
소리 끄기 상태면 컨텍스트를 아예 만들지 않는다.

### 화면 흔들림 3단계

| 단계 | 어디 | 세기 |
|---|---|---|
| `tap` | 유닛 캔버스 | 1.5px, 90ms |
| `hit` | 스테이지 | 3px, 220ms (해금 · 화재 · 도난) |
| `quake` | 스테이지 | 5px, 900ms (문명 전환 — 도시가 무너진다) |

`설정 > 애니메이션 > 줄이기` 를 켜면 흔들림과 링 펄스가 전부 꺼진다 (`.reduced`).
`설정 > 소리` 토글도 추가했다.
